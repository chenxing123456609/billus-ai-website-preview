# 官网2.0共享样式规范

本轮范围：只调整首页 WORKSPACE 展示区（图1参照图2）及智能体产品页首屏（图3参照图4）。继承现有样式，不重设全站视觉。2026-11-19 用户已确认两张参考图的对应关系。

## 现有共享层（锁定）

- 字体：本地 OPPO Sans，继承已有常规、粗体字体文件。
- 色彩：使用 style.css 的 --page、--surface、--soft、--text、--muted、--brand、--line；浅色品牌绿 #38872a，深色品牌绿 #9bdf78。产品首屏依参考图使用固定深底与品牌绿色光束。
- 内容网格：沿用 .wrap，最大1200px，桌面左右48px，平板32px，手机20px；内容、标题、按钮与图片对齐同一网格。桌面可按12列理解，本轮功能区为5/12文案、7/12视觉，手机单列。
- 导航：现有82px桌面、68px手机导航与二级菜单，保留当前展开、当前页和手机交互。页脚及其快捷链接、二维码保持现有实现。
- 普通按钮：沿用 .button、.button-green、.button-outline；默认最小46px高、22px横向内距、13px文字、胶囊圆角。局部主按钮可在现有尺度内用48至52px高；中号36px、小号28px；手机主按钮至少44px。
- 按钮状态：继承悬停、按下、禁用、加载及可见焦点；下载和补丁按钮复用已有弹窗，不增加虚构下载地址。按钮标签不换行。
- 侧栏按钮、分页按钮：保持已有服务支持和新闻实现，本轮不修改。
- 选中与未选中：功能标签采用实底选中、透明未选中，文字与背景有清晰对比；aria-selected、tabindex与视觉状态一致。
- 字号：继承现有字体；本轮区块标题桌面32至36px、小标题28至32px、正文16px、辅助14px。产品页大字为用户参考图的特定例外，桌面主标题最大88px，英文副标题约32px；手机主标题38px左右，其他标题26至30px、正文14px、辅助不低于12px。
- 行高：多行标题约1.3，正文1.6至1.85；大标题与说明、操作区分别留24至32px、32至40px。
- 卡片与图片：继承细边框与小圆角；功能截图边框1px、圆角约8px，不套额外装饰卡片。图内信息与边缘至少24px。知识接入示意明确标注“示意”，不当成真实产品截图。
- 图标：复用现有 Icon 组件的同一套线性图标，标准16px或24px，纯装饰图标 aria-hidden。
- 动效：沿用160至240ms ease-out的颜色、边框反馈；页级动效保留已有实现；卡片统一轻微边框或背景变化，不混入不同悬浮效果。尊重 prefers-reduced-motion。
- 视觉真实性：使用现有真实客户端和成果图片；第三方参考图只提供布局、层级和光束构图，不复制第三方名称、终端运维能力或统计数字。

## 局部组件约定

- 首页：居中区块标题、三个可键盘切换的标签、左文右图；标签分别展示项目工作台、企业知识库、方案与成果，内容依据本地毕鲁斯产品知识。
- 产品页：居中品牌大标题、英文产品名、说明与原有下载/补丁操作，深色品牌光束背景，四项现有能力说明；不填写没有依据的用户数、模型数或业绩。
- 手机：功能区按标题、标签、文案、视觉排列；标签自适应三等分；首屏能力条改为2列，按钮和文字不溢出。
- 可访问性：标签使用 tablist/tab/tabpanel、左右方向键及Home/End、可见焦点；图片有中文/英文替代文本；语言切换继续使用现有 t() 字典。VoiceOver/TalkBack读取标签选中状态和面板关联。

## 完成标准

检查两处桌面与手机布局、标签键盘与点击、深浅主题、英文、下载与补丁弹窗，以及首页其他区域、导航和产品页后续内容未被改动。

## 自研模型与首页咨询区补充（2026-11-19）

- 模型页首段采用左侧品牌标题、说明与档案入口，右侧四条图标能力说明；沿用本页现有纯色背景、OPPO Sans 和主题变量。
- 模型能力按毕鲁斯材料改写为图文空间表达、行业图像生成、图像编辑、企业知识与智能体协同；不套用参考公司的语音理解、超长上下文、推理性能或安全保证。
- 现有公开版本说明和往期模型档案保留，模型能力与具体版本的发布信息分层表达。
- 首页原“关于毕鲁斯”双栏区替换为居中标题、说明与项目咨询按钮；保留该区原有 --soft 背景与边框，不增加参考图中的山景、照片或渐变。
- 桌面模型说明按左右双栏；800px以下堆叠。四条能力使用同族24px线性图标、52px图标底，手机缩为44px。首页咨询区最大1000px居中，正文最大850px。
- 新增文案同步英文；咨询按钮进入现有联系销售页，模型按钮进入现有模型档案页。检查手机换行、深浅主题及原有工作台和智能体首屏不受影响。

## 顶部导航批注更新（2026-11-19）

- 顶部操作顺序改为：下载智能体、独立中英文切换、手机导航菜单。
- 移除顶部“访问模型广场”按钮及明暗主题切换。页面统一使用现有浅色主题，不再读取已存储的深色偏好；首页深色品牌首屏等局部视觉保持原状。
- 产品菜单与正文中的模型广场入口保留。语言切换沿用原有行为与本地保存方式。

## 一级、二级导航黑色外观（2026-11-19）

- 一级顶栏、二级下拉菜单、产品二级导航和关于我们二级导航统一使用纯黑背景。
- 导航内局部使用浅色文字、明亮品牌绿、深灰边框和深绿色悬停/选中底；下载按钮保持品牌绿并使用深色字。
- 手机菜单沿用相同黑色导航方案。颜色变量只在导航容器内覆盖，正文仍使用现有浅色主题，明暗模式切换继续保持移除状态。

## 首页导航入口（2026-11-19）

- 一级导航首项为“首页”，位于“产品”左侧，中文/英文分别显示首页/Home，并标记首页当前状态。

## 产品页面包屑补充（2026-11-19）

- 产品页“首页 / 产品 / 当前产品”所在整条区域使用纯黑背景，覆盖左右留白及二级导航上方的间距。
- 面包屑使用浅灰文字、亮色当前页和绿色链接悬停态。保留原有内容宽度与纵向位置，正文背景不变。

## 产品页顶部辅助导航隐藏（2026-11-19）

## 最新面包屑与横向二级栏要求（2026-11-19）

- 所有页面的面包屑均显示为通栏白底、深色文字；覆盖产品、模型、文档、公司、团队、新闻与联系页。保留“首页”跳转和当前页文字。
- 产品页和关于我们页面的横向二级导航统一隐藏，不占高度；一级黑色导航与其下拉菜单继续保留。
- 面包屑使用现有1200px内容对齐基线，桌面/平板/手机分别保持对应安全边距；手机长内容允许换行。
- 面包屑作为导航信息直接显示，不参与正文滚动显现动效。此条覆盖此前面包屑隐藏和黑色背景要求。

## 联系销售二维码（2026-11-19）

## 首页滚动吸附与 API 首屏精简（2026-11-20）

- 按最新截图移除 API 首屏下方整条圆形接入符号与曲线，不保留该区域占位；首屏按钮之后直接衔接四项能力卡片。
- 首页主内容按一屏一个区块组织，顶部对齐到现有导航下缘；桌面首屏、智能体、空间展示、价值、产品、支持、咨询及页脚使用原有色彩和内容。
- 桌面纵向滚轮每次有效手势平滑进入相邻区块，合并触控板惯性；向上滚动可回到上一屏。触摸与键盘使用原生吸附，正常保留焦点及链接。
